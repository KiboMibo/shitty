Пункты 2, 3, 23, 32, 33, 36, 44 (dw-шрифты, шрифтовый фолбек, пустые клетки) — отдельный заход, в этом проходе не делаются.

1. Metal: гонка CPU/GPU на общем cellBuffer — framesInFlight=3, но буфер обновлений один; draw() ждёт только fence кадра N-3, а кадры N-1/N-2 ещё могут читать буфер, который перезаписывает buildCellUpdates(). Рваные кадры под нагрузкой. Vulkan-путь сделан правильно (per-frame буферы) — Metal надо привести к нему (render_metal.mm:290,740-752,843-847).
2. CJK/emoji из коробки — пустые клетки: без валидного dwfont широкие символы рендерятся пустотой (return 0 слот), а дефолт 18x18ja почти никогда не проходит проверку «ровно 2×». Fallback-цепочки по покрытию кодпоинтов нет вообще (render_vk.cpp:1748, font_pack.cpp:136, options.cpp:39).
3. Правило dwfont «ровно вдвое шире» ломается округлением и падает молча: точное равенство width/height/baseline двух разных шрифтов случайно; отказ проглатывается createOptional без единого лога — пользователь с явным -dwfont получает пустые ячейки без диагностики (font_freetype.cpp:215-217,259-261, font_pack.cpp:66-72).
4. Cocoa IME: двойная доставка клавиш — keyDown: шлёт key-событие в терминал до interpretKeyEvents: без проверки hasMarkedText; Enter при выборе кандидата уходит и как commit, и как \r в pty; стрелки/Escape при навигации по кандидатам — тоже (platform_cocoa.mm:179-183).

16. PtyOutputQueue без верхней границы — решено не чинить (по указанию).
20. Vulkan: исключение между vkResetFences и vkQueueSubmit → несигналенный fence навсегда (сейчас спасает только то, что исключение убивает процесс; любой будущий retry превратит в дедлок) (render_vk.cpp:2350).
21. Без maintenance1 retired-свопчейны копятся до 8 (сотни МБ + WaitIdle-хитч посреди ресайза) (render_vk.cpp:1339).
22. В кодовой базе пять UTF-8-декодеров — сведение к одному не сделано (строгость plt-декодера починена отдельно).
23. Индийские кластеры с матрами (Mc→Wide) уводятся в CJK-шрифт → тофу (grapheme.cpp:482).
29. Headless-поллер no-op — решено не делать (исключено ранее вместе с plt-переделкой headless).

Недоделки

48. Underline на DECDHL рисуется в обеих половинах.
