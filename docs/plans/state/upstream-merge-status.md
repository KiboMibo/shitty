## Унаследованные знания о среде — во все брифы этого плана

Куплены дорого в прошлом плане, каждое стоило отдельного разбора:

| Что | Почему важно |
|---|---|
| Сборка **штатным Apple clang**, `CC`/`CXX` не выставлять | Homebrew LLVM не установлен, `brew --prefix llvm` даёт несуществующий путь, сборка падает с `FileNotFoundError` |
| Полное окружение питоновских тестов: `SHITTY_TEST_BINARY`, **`SHITTY_PRETTY_TEST_BINARY`** (не `PRETTY_TEST_BINARY`), `SHITTY_TOML_DUMP_BINARY`, `SHITTY_TEST_FONTCONFIG`, `SHITTY_TEST_PLATFORM`, `SHITTY_TEST_VERSION` | Неполное окружение даёт ложные отказы. На этом обожглись четверо, включая командира; из-за этого регрессия дошла до `master` |
| Питоновские тесты запускаются **только из каталога `tst/`** | Из корня падают на `from harness import Shitty` |
| `pty_test_helper` **не собирается** целью `unit_tests` | Без отдельной сборки пять `Pty::*` ложно падают с «Error: execvp» |
| **НЕ запускать `python3 dev/style.py`** | clang-format 23.1.0 против ожидаемого 21; прогон переформатирует ~130 чужих файлов |
| **Не использовать `tr`** в конвейерах | Был алиасом на `task add` в профиле пользователя; снят, но привычка полезна |
| Параллельные задачи — **каждая в своём worktree** | Иначе переключают ветку под соседом; `pkill` по шаблонам в общем дереве запрещён |
| **Пустой вывод `./build <guard>` не доказывает прогон** | `.build/` адресуется содержимым, штампы возвращаются из `.build/cas/` без исполнения. Гвард подтверждается тем, что **краснеет на нарушении** |
| Комментарии в коде — **без номеров строк** | Протухают за одну волну |
