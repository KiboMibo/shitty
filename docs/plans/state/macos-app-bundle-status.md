Начато: 2026-08-15

## Задача

Терминал распространяется голыми бинарями `st`/`pt`. Нужен macOS-бандл `.app`,
чтобы приложение запускалось из Finder/Spotlight/Dock, имело нормальное имя в
меню и иконку из `Info.plist`, а не из рантайм-хака.

Скоуп выбран пользователем: **только скрипт упаковки**, без правок `build.py`
и без изменений `release.yml`.

## Решения (принято командиром, можно оспорить)

| Вопрос | Решение | Почему |
|---|---|---|
| Формальный `/coding-plan` | Пропущен | Одна задача в одну волну; плановая машина дороже работы |
| Проверочная волна | Только QA-приёмка | Нет продакшн-кода, нет данных/секретов; тесты и секьюрити-ревью на shell-скрипт упаковки не дают выигрыша |
| Бинарь для проверки | `brew install pg83/tap/{shitty,pretty}` | Локальная сборка требует ragel + Homebrew-LLVM (~2 ГБ); скрипт от источника бинаря не зависит |
| Подпись | ad-hoc (`codesign -s -`) | Нотаризация требует Developer ID — это решение пользователя, не командира |

## Контекст, который нашли в коде

- `ext/plt/platform_cocoa.mm:852` — `NSApplication` + `ActivationPolicyRegular`: это уже GUI-приложение.
- `ext/plt/platform_cocoa.mm:1088` — иконка Dock ставится в рантайме именно потому, что бандла нет.
- `build.py:494` — `icon_png()` растеризует `shitty.svg`/`pretty.svg` в 1024×1024 PNG через `rsvg-convert`.
- Бренды: `Shitty`/`st`/`shitty` (`main_shitty.cpp`), `Pretty`/`pt`/`pretty` (`main_pretty.cpp`).

## Отложено / к сведению

- **Коллизия имени `pt`.** Формула `tcl-tk` ставит свой `pt` в `/opt/homebrew/bin`,
  перекрывая `pg83/tap/pretty`; на такой машине скрипт упаковки подхватит чужой
  Tcl-скрипт вместо терминала. Исполнитель развёл это локально
  (`brew link --overwrite pretty`). Это состояние brew на машине, а не дефект
  репозитория, но при упаковке из `PATH` стоит держать в уме — возможный повод
  для проверки бинаря в скрипте. Решение отложено: скоуп задачи этого не требует.
