## Задача

Пользователь: «при сплите панелей в новой панели нельзя запустить приложение с TUI, оно просто не запускается». Разведка показала другое: TUI запускается и работает, а окно навсегда перестаёт презентовать кадры при переходе любой панели на альтернативный экран. Дефект не специфичен для новой панели.

Второй план — `docs/plans/2026-08-29-upstream-merge.md`, исполняется после этого.

## Решения пользователя

| Вопрос | Решение |
|---|---|
| Порядок работ | Сначала фикс бага на текущем master, потом мерж апстрима |
| Вариант фикса | Вариант 2 сейчас (ответ на отказ рендерера), вариант 1 — условно, после замера |
| Тестовый режим | Чинить отдельной задачей **до** фикса: без этого регрессию нечем поймать в `tst/*.py` |
| Находка Т2 (начальный `winsize`) | Отдельной задачей в части 1 |
| Апстримный `lib/embed` | Просто втащить и собирать, своей работы поверх не делать |
| Объём мержа | Весь апстрим, 8 волн |
| Режим мержа | Автономно до волны 9 (по нумерации плана мержа — до волны 6, задача `T5.1`) |
| Структура | Два отдельных плана, а не один общий |
