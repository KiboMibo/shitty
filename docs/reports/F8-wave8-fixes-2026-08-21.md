## Шаг 1: отрицательный контроль (базис `e74011b8`, дерево `/tmp/f8`)

Сборка и измерение — разными командами.

| прогон | код выхода | тестов |
|---|---|---|
| `SHITTY_PTY_TEST_HELPER=$PWD/.build/pty_test_helper .build/unit_tests --threads=1` | 0 | `OK: 892` |
| тот же бинарь под `MallocScribble=1 MallocPreScribble=1` | **139 (SIGSEGV)** | обрыв в наборе `SessionSet`, после `ADragKeepsReachingThePaneItsPressLandedIn` |

Моё число тестов на базисе — **892**, как у ревьюера, а не 888 из постановки. Расхождение не разбирал.

Каждый подозреваемый тест по отдельности под заливкой:

| тест | код выхода |
|---|---|
| `SessionSet::AShellThatExitsTakesItsPaneAndLeavesTheTabStanding` | 139 |
| `SessionSet::ClosingAPaneGivesItsRoomToTheSurvivorAndKeepsTheTab` | 139 |
| `SessionSet::ClosingTheLastPaneOfATabClosesTheTab` | 139 |
| `SessionSet::TheCloseChordTakesThePaneAndOnlyThenTheTab` | 139 |
| `SessionSet::CloseTabDestroysItsWholeArena` (контроль: закрытие вкладки) | 0 |

Падают четыре, а не три — постановка называла три, ревью называло четыре; воспроизвелись все четыре.
Закрытие **вкладки** не падает, что подтверждает разбиение из ревью.

## План работ

1. **Отрицательный контроль.** Собрать базис `e74011b8` и снять падение под `MallocScribble=1 MallocPreScribble=1`.
   Ожидание по ревью: код выхода 139 на `AShellThatExitsTakesItsPaneAndLeavesTheTabStanding`,
   `ClosingAPaneGivesItsRoomToTheSurvivorAndKeepsTheTab`, `TheCloseChordTakesThePaneAndOnlyThenTheTab`.
   Плюс своё число тестов на чистом прогоне (ревью насчитало 892, задача называет 888 — сверяю сам).
2. **F-S1.** Убрать use-after-free на пути закрытия панели. Выбор уровня починки — после чтения кода
   `retire()`/`closePane()`/`runReaper()`/`ptyEof()`; обоснование и оставшийся открытым класс — в этом отчёте.
   Отдельно решить судьбу `canReap()`, который в момент вызова из `retire()` спрашивает про предшественника.
3. **F-S2.** Гасить `pressedPane_`, `pressedButtons_`, `draggedSplit_` там же, где гасится `overDivider_`
   (`focus(false)`, `pointerPresence(false)`), и при смене активной вкладки.
4. **F-S3.** Дать `SessionSet` публичный ответ «какой терминал под этим пикселем» и брать его
   в `VtermDropTarget::dropped()` по координатам отпускания.
5. **Тесты.** Четыре новых теста (закрытие сфокусированной панели; нажатие → потеря фокуса окна → нажатие
   в соседней панели; нажатие в панели вкладки 1 → `nextTab()` → движение; отпускание файла над правой панелью).
   Каждый — с мутационной пробой. Дописываю в конец `session_ut.cpp`, существующее не переставляю
   (параллельно в файле работает `R8-qa`).
6. **Приёмка.** Чистый прогон + прогон под `MallocScribble` с кодом выхода 0 и числом тестов.

## Правила прогона

- Сборка и измерение — разными командами.
- Тесты коммитятся до мутационных проб; мутация откатывается по конкретному пути файла.
- Число тестов печатается рядом с каждым результатом.
