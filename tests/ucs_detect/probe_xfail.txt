# Exact differences from data/zutty.yaml at upstream revision ea4510a4.
# The recorded profile predates support for the xterm/Contour color-scheme
# query.  Zutty implements CSI ? 996 n and correctly returns CSI ? 997;1 n for
# its configured dark scheme, so absence in the old profile is not an oracle.
# https://contour-terminal.org/vt-extensions/color-palette-update-notifications/
color_scheme
# Xterm 410 lists all of these strings as valid DECRQSS requests and requires
# DCS 1 $ r Pt ST responses containing their current CSI setting.  The old
# profile records no support (and accidentally stores the DA1 capability list
# as its DECSCL value); Zutty's `0"q`, `2 q`, `64;1"p`, margins and `0m`
# replies follow the protocol.
# https://invisible-island.net/archives/xterm/xterm-410.tgz
decrqss_decsca
decrqss_decscusr
decrqss_decscl
decrqss_decslrm
# Xterm 410 ctlseqs.txt lists `t` as the valid DECSLPP DECRQSS request,
# and misc.c answers it with the current line count (at least 24).  Zutty's
# `24t` is therefore correct; the imported ea4510a4 profile omits this newer
# capability and expects no response.
decrqss_decslpp
decrqss_decstbm
decrqss_sgr
# The recorded 0.16-1 profile says DECRQSS cannot report truecolor SGR.
# Xterm 410 xtermFormatSGR() serializes direct foreground/background colors,
# and Zutty now returns the equivalent canonical 38:2::r:g:b form, so the
# detector correctly changes from false to true.
# https://invisible-island.net/archives/xterm/xterm-410.tgz
decrqss_truecolor
# The recorded DA1 omits printer, selective erase, user-defined keys,
# rectangular editing and ANSI locator capabilities which this fork actually
# implements.  Xterm/DEC assign those advertised parameters 2, 6, 8, 28 and
# 29 respectively; truthful capability advertisement must differ from the
# older profile.
# https://invisible-island.net/archives/xterm/xterm-410.tgz
device_attributes
# Kitty's keyboard protocol defines CSI ? u as the flags-stack query and a
# CSI ? flags u response.  Zutty's zero-flags response is real support absent
# from the recorded profile.
# https://sw.kovidgoyal.net/kitty/keyboard-protocol/
kitty_keyboard
# DECRQM/DECRPM requires a response for queried private modes: state 1/2 for
# supported set/reset modes and state 0 for unrecognized modes.  The profile
# records silence for all of these; Zutty instead reports its actual support
# (or 0 for 2027/5522) as xterm specifies.
# https://invisible-island.net/xterm/ctlseqs/ctlseqs.html
mode_bracketed_paste
mode_bracketed_paste_mime
mode_color_palette_updates
mode_focus_in_out_events
mode_grapheme_clustering
mode_in_band_window_resize
mode_mouse_extended_sgr
mode_synchronized_output
# Xterm's XTGETTCAP explicitly recognizes Co/colors, RGB and TN in addition to
# key capabilities.  Zutty returns 256 colors, 8-bit RGB components and its
# xterm-256color terminal name; the recorded profile's None values are stale.
# https://invisible-island.net/xterm/ctlseqs/ctlseqs.html
xtgettcap_Co
xtgettcap_RGB
xtgettcap_TN
xtgettcap_colors
